| Path      | Contents                                                 |

## Repository rules

- Files tied to a date start with it, in the format `YYYY-MM-DD-`: `2026-11-23-progress-review.pdf`.
- Files named in English, lowercase, with words separated by hyphens (kebab-case): `market-analysis.docx`, not `Analisi_Mercato.docx`.
- Everything that would be delivered to a client is in English. Only internal documents (such as task tracking) and presentations to the client and the teachers are in Italian.
- Use the terms in [rules/glossary.md](rules/glossary.md).
